# Governance

Organelle uses a maintainer-led model. Maintainers review contributions, manage releases
and security reports, define the roadmap, and enforce community standards. Routine
decisions are made by lazy consensus in public issues and pull requests. Material
changes to licensing, governance, security boundaries, stable APIs, or data
compatibility require explicit approval from at least two maintainers when the project
has two or more active maintainers.

Maintainers are selected for sustained, constructive contributions and sound judgment.
Existing maintainers nominate and approve new maintainers. A maintainer may step down at
any time or be removed for prolonged inactivity, conflicts of interest, or Code of
Conduct violations.

The current maintainers and contact routes are listed in
[MAINTAINERS.md](MAINTAINERS.md). Until that list contains named, authorized release
maintainers, releases must not be published.
