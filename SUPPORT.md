# Support

Organelle is community-supported. Use GitHub Discussions for setup and usage questions
and GitHub Issues for reproducible defects or scoped feature proposals. Search existing
reports first and include the exact version, deployment method, relevant redacted logs,
and reproduction steps.

There is no guaranteed response time or commercial support commitment. Security
vulnerabilities belong in private vulnerability reporting, not discussions or issues.
General PostgreSQL, container platform, identity-provider, or reverse-proxy
administration may fall outside the project scope.
